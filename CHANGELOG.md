# Changelog

## Latest project update

- Added a Settings → BSP area for managing imported BSP maps.
- BSP imports keep the source map and map-associated generated files together; deleting a map removes its associated data without targeting shared game assets.
- Connected the cutscene plugin to the loaded map and exposed its playback control in the interface.
- Updated the README usage and feature documentation in English and Russian.

> Cutscene playback and BSP conversion should still be tested against the specific maps and game assets you use.
