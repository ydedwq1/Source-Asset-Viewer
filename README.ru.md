# Source Asset Viewer

Браузерный просмотрщик ресурсов игр на движке Source (и частично Source 2): карты, модели, текстуры и музыка. Работает полностью на клиенте, без сервера и сборки — всё открывается и хранится локально в браузере.

## Возможности

### 🗺 Карты
- Открытие `.vmf` (Source 1) и `.vmap` (Source 2 / CS2, DMX binary 5–9). Также принимаются `.vmx`, `.map`, `.txt`.
- Импорт BSP-карт через встроенный конвертер BSP → VMF; исходный BSP и подготовленные файлы карты хранятся вместе в разделе BSP настроек.
- Построение геометрии из брашей, поддержка дисплейсментов и смешивания текстур (blend).
- Текстуры VTF, прозрачное стекло, триггеры, скайбокс (включая 3D-скайбокс), сущности и иконки сущностей.
- Модели props внутри карты и точки крепления (attachments).
- Статистика: брашы, полигоны, треугольники, сущности, материалы, дисплейсменты, размер карты.
- Экспорт в **GLB** (с опциями: сущности, триггеры, максимальный размер текстур до 4096), скриншоты (в том числе HD ×2), каркасный режим.

### 📦 Модели
- Парсеры `.mdl`, `.vvd`, `.vtx`, `.phy`.
- Скины (skin families), bind pose, физическая модель.
- Галерея миниатюр, поиск и фильтр по игре.
- Экспорт в **GLB**, **OBJ**, **SMD**.

### 🖼 Текстуры
- Просмотр `.vtf` с навигацией по папкам, поиском и ленивой подгрузкой миниатюр.

### 🎵 Музыка
- Плеер для `mp3`, `ogg`, `wav` (включая MS-ADPCM и IMA-ADPCM) с плейлистом, shuffle и repeat.
- Скачивание отдельных треков и ZIP-архивом, конвертация форматов.

### 📚 Архивы и хранилище
- Чтение **VPK** (v1 и v2, в том числе многотомные), **WAD3** и **PAK**.
- Защита от «бомб»: лимиты на размер дерева, число файлов и суммарный объём.
- Файлы ресурсов сохраняются в **IndexedDB** (дедупликация по SHA-256, сжатие), есть окно управления хранилищем: объём, квота, удаление всех `.vtf` или всего.
- Для импортированных BSP-карт есть отдельный список в настройках: карту можно удалить вместе с принадлежащими ей сохранёнными файлами. Общие ресурсы игры не должны удаляться вместе с картой.
- Фильтр по играм — определяется по пути в VPK или по структуре папок.

### 🎬 Кат-сцены
- Плагин кат-сцен подключается к загруженной карте и позволяет запускать воспроизведение через кнопку в интерфейсе.
- Поддержка зависит от структуры карты и наличия нужных сущностей/анимаций; некоторые сцены могут требовать дополнительных ресурсов игры.

### 🌐 Интерфейс
- 13 языков: ru, en, uk, de, fr, es, it, pt, pl, tr, zh, ja, ko (`i18n.json`).
- Язык определяется автоматически и запоминается.
- Адаптивная вёрстка, работает на мобильных устройствах.

## Структура проекта

| Файл | Назначение |
|---|---|
| `index.html` | Разметка интерфейса: вкладки, панели, модальное окно хранилища |
| `i18n.json` | Переводы интерфейса |
| `core.js` | Ядро: i18n, хранилище (IndexedDB), упаковка, фильтр по играм, drag & drop |
| `archives.js` | Парсеры VPK / WAD3 / PAK |
| `vmf.js` | Загрузка и рендер карт VMF/VMAP, экспорт GLB |
| `vmap.js` | Парсер карт Source 2 (DMX binary) |
| `models.js` | Парсеры MDL/VVD/VTX/PHY, просмотр моделей, экспорт GLB/OBJ/SMD |
| `textures.js` | Вкладка текстур VTF |
| `music.js` | Аудиоплеер и экспорт звука |

Также `index.html` и модули подключают файлы `app.js`, `style.css`, `pack.js`, `vtf.js` и `export.js` — они должны лежать рядом.

## Запуск

Сборка не нужна. Приложение использует ES-модули, поэтому открывать `index.html` через `file://` нельзя — запустите любой статический сервер:

```bash
# Python
python3 -m http.server 8080

# или Node.js
npx serve .
```

Затем откройте `http://localhost:8080`.

Для работы нужен интернет: **three.js 0.160.0** подгружается с CDN (unpkg) через `importmap`. Для офлайн-работы скачайте библиотеку локально и поправьте пути в `importmap` внутри `index.html`.

## Как пользоваться

1. Перетащите файл карты (`.vmf`, `.vmap`) или папку с ресурсами во вкладку «Карты». BSP-карту импортируйте через встроенный конвертер; затем управляйте её сохранённой копией в настройках → BSP. Можно загружать `.vpk`, `.wad`, `.pak` и папки с `.vtf`, `.mdl`, `.png`-иконками.
2. Для текстур, моделей и звуков дропните нужные архивы или папки — они попадут в локальное хранилище и станут доступны во всех вкладках.
3. Откройте окно хранилища (плашка «Файлы» вверху), чтобы посмотреть, что загружено, или освободить место.

Управление в 3D: **ЛКМ** — вращение, **ПКМ** — панорама, **колесо** — зум.

## Требования

- Современный браузер с поддержкой ES-модулей, WebGL и IndexedDB (Chrome, Edge, Firefox, Safari).
- Для экспорта звука в `ogg`/`mp4` нужна поддержка соответствующих кодеков в браузере.

## Технологии

JavaScript (ES-модули), [three.js](https://threejs.org/) (OrbitControls, GLTFExporter, ConvexGeometry, RoomEnvironment), IndexedDB, Web Audio. Без фреймворков и сборщиков.
